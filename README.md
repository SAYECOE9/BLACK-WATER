## 📖 About The Project

**Black Water** is a cinematic, minimal landing page template built using **Tailwind CSS** and modern **CSS3** backdrop effects. The interface recreates the mystery of deep-sea exploration using focused radial lighting, bold tracking typography, and frosted glass elements.

### 🌟 Key Features
* **Glassmorphism Navigation:** Translucent navigation bar and action buttons with `backdrop-blur` filters.
* **Striking Typography:** Oversized glowing headlines (`title-shine` & `water-text`) with generous character spacing.
* **Vertical Social Links:** Rotated side navigation (`rotate-[90deg]`) for a sleek, modern layout.
* **Atmospheric Depth:** Multi-layered background overlays, center ambient glow, and dark vignette edges.
* **Fully Responsive:** Seamlessly scales across mobile, tablet, and desktop screens.
